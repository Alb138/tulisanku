# TULISANKU

*Tulisanku* means "my handwriting". Write a few letters on paper, and TULISANKU generates
every other letter in the same handwriting style, packaged as a font you can type with.

Final project for COMP6826001 Deep Learning, BINUS University.

## How it works (overview)

1. **Learn what letters are** from ~2,000 free fonts (Google Fonts), rendered as images.
2. **Learn real handwriting** from NIST Special Database 19 (handprinted characters, organized by writer).
3. **Few-shot generation**: given a few letters of someone's handwriting, generate the rest.
   We compare a nearest-font baseline, a GAN we build ourselves, and a diffusion model.
4. **Evaluate** against people's real handwriting (similarity, legibility, "real or AI?" test).
5. **Package** the generated letters into a font file and serve it in a web app.

## Project structure

```
tulisanku/              Python package (reusable code)
  charset.py            the 62 characters we generate (0-9, A-Z, a-z)
  google_fonts.py       find and download fonts from the Google Fonts repo
  render.py             turn a font into baseline-aligned glyph images
  cleaning.py           rules for removing symbol, faint and duplicate fonts
  nist.py               NIST SD19: label join, scan cleaning, baseline rebuilding
  template.py           layout of the printable handwriting sheet
  download.py           parallel, resumable downloader (the NIST server is slow)
scripts/
  build_font_dataset.py Google Fonts -> fonts_<size>.npz / .csv / preview
  clean_font_dataset.py decide which fonts to keep -> fonts_<size>_quality.csv + contact sheets
  download_nist.py      NIST SD19 by_write.zip (by_class.zip is fetched the same way)
  build_nist_dataset.py NIST -> nist_<size>.npz (images + mask) / .csv / preview
  make_template_sheet.py templates/tulisanku_sheet.pdf
collect/
  app.py                handwriting collection page (Flask): draw each character on a phone
templates/
  tulisanku_sheet.pdf   printable alternative to the collection page
notebooks/
  01_build_font_dataset.ipynb   builds and cleans the font dataset on Kaggle (fallback)
```

## Running

Developed and trained locally on an RTX 3050 Laptop GPU (4 GB); the Kaggle notebook in
`notebooks/` is a fallback for larger runs.

```bash
python -m venv .venv
# GPU build of PyTorch first (CUDA 12.8 wheels), then the rest
.venv/Scripts/python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
.venv/Scripts/python -m pip install -r requirements.txt   # Windows; use .venv/bin/python on Linux/macOS

.venv/Scripts/python scripts/build_font_dataset.py          # ~1 GB of fonts -> data/processed/fonts_64.*
.venv/Scripts/python scripts/clean_font_dataset.py          # -> fonts_64_quality.csv + contact sheets
```

## Collecting handwriting

The page is hosted on PythonAnywhere for a permanent link - see [collect/DEPLOY.md](collect/DEPLOY.md)
(setup, monthly renewal, and `scripts/fetch_collected.py` to download the drawings). It can also run
from a laptop:

```bash
.venv/Scripts/python collect/app.py           # address for phones on the same Wi-Fi
.venv/Scripts/python collect/app.py --share   # temporary public https link via Cloudflare
```

`--share` needs Cloudflare's free `cloudflared` program: install it with
`winget install --id Cloudflare.cloudflared` (then open a new terminal), or download
`cloudflared-windows-amd64.exe` from https://github.com/cloudflare/cloudflared/releases and save it as
`tools/cloudflared.exe`. The laptop must stay on while people use the link, and the link changes on
every restart.

Each character is saved as it is drawn to `data/raw/handwriting/drawn/<session>/` (image + pen strokes).
Data stays on the laptop running the server and is never committed. Uploads are limited to 2 MB and
must be PNG images.

## Data and licenses

- **Google Fonts**: mostly SIL Open Font License (OFL). Per the OFL FAQ, fonts generated by a model
  trained on OFL fonts are derivative works, so fonts produced by TULISANKU are released under the OFL.
- **NIST Special Database 19**: used under NIST's open-use terms.
- **Self-collected handwriting**: collected with written consent; not redistributed.
