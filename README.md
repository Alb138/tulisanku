# TULISANKU

*Tulisanku* means "my handwriting". Write a few letters on paper, and TULISANKU generates
every other letter in the same handwriting style, packaged as a font you can type with.

Final project for COMP6826001 Deep Learning, BINUS University.

## How it works (overview)

1. **Learn what letters are** from ~2,000 free fonts (Google Fonts), rendered as images.
2. **Learn real handwriting** from NIST Special Database 19 (handprinted characters, organized by writer).
3. **Few-shot generation**: given a few letters of someone's handwriting, generate the rest.
   We compare a nearest-font baseline, a GAN we build ourselves, and a diffusion model.
4. **Evaluate** against people's real handwriting (similarity, legibility, "real or AI?" test).
5. **Package** the generated letters into a font file and serve it in a web app.

## Project structure

```
tulisanku/              Python package (reusable code)
  charset.py            the 62 characters we generate (0-9, A-Z, a-z)
  google_fonts.py       find and download fonts from the Google Fonts repo
  render.py             turn a font into baseline-aligned glyph images
  cleaning.py           rules for removing symbol, tiny-letter and duplicate fonts
scripts/
  build_font_dataset.py Google Fonts -> fonts_<size>.npz / .csv / preview
  clean_font_dataset.py decide which fonts to keep -> fonts_<size>_quality.csv + contact sheets
notebooks/
  01_build_font_dataset.ipynb   builds and cleans the dataset on Kaggle
```

## Running

Heavy steps (dataset building, training) run on **Kaggle notebooks**, which clone this repo.
To try things locally:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Windows; use .venv/bin/python on Linux/macOS
.venv/Scripts/python scripts/build_font_dataset.py --categories HANDWRITING --limit 24
```

## Data and licenses

- **Google Fonts**: mostly SIL Open Font License (OFL). Per the OFL FAQ, fonts generated by a model
  trained on OFL fonts are derivative works, so fonts produced by TULISANKU are released under the OFL.
- **NIST Special Database 19**: used under NIST's open-use terms.
- **Self-collected handwriting**: collected with written consent; not redistributed.
